# gross.dev

This is my professional portfolio/blog site. I can't promise there won't be any
personal content, but I'll try to restrain it to what potential employers and
colleagues should know.

## Technical notes

Site uses the static site generator [Zola](https://www.getzola.org). I chose it
from among the myriad other options because it seemed about right for my needs
and gives me the opportunity to learn something new. (Note those are not the
criteria I would use if I were getting paid by an employer/client.)

The theme for the site is [Linkita](https://github.com/salif/linkita), chosen
because it had the features I wanted (support for light/dark themes, responsive
design, diagrams using Mermaid, search support, and robust configuration
options) and also decision fatigue.
